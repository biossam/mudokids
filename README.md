# 무.도.키즈 (mudokids)

출처: 무.도.키즈 교사연구회, NAVER CONNECT, TEACHERS LAB 5

화면 밖으로 나와 함께 뛰다! 실천형 휴먼 프로젝트 「RUNNING MAN」 — 초등 5~6학년 AI 융합 10차시 프로그램 소개 사이트입니다. 성장 MAP·휴먼스킬아트 사이트와 같은 글꼴(제목 Gaegu, 본문 Gothic A1)로 만들었습니다.

- 사이트: https://biossam.github.io/mudokids/

| 구역 | 내용 |
|---|---|
| 탭 | 소개 · 10차시 · 수업 안내 · 체크리스트 · 수업 이야기 (주소 #intro #lessons #guide #check #stories) |
| 첫 화면 | R·U·N·N·I·N·G·M·A·N 머리글자 — 누르면 10차시 탭에서 그 차시 카드가 펼쳐짐 |
| 무.도.키즈는요 | 연구회 소개, 연구 내용 |
| 어떤 문제에서 출발했나요? | 학생의 말, 문제 한 문장, 왜 AI를 쓰나요, 기대한 변화 |
| RUNNING MAN 10차시 | 차시별 핵심 질문·휴먼스킬·주요 활동 (세 구간을 주황·파랑·초록으로 구분) |
| 운영 안내 | 학교급·차시·키워드, 성취기준, 지도 중점, 3단계 압축 운영안 |
| 교실 링크로 함께 쓰는 활동지 | 웹 활동지 사용 순서 안내 |
| 체크리스트 | AI 도구 쓰기 전 체크리스트 (화면에서 체크만, 저장 안 됨) |
| 수업 이야기 | 1차 수업에서 바꾼 점 · 실제 변화 · 따라 하기 체크리스트 · 우리 학교에 맞게 — **준비 중** |

차시별 수업 슬라이드·활동지·수업 안내는 연구회 수업 지도안을 바탕으로 구성했습니다.

## 차시 화면 (성장 MAP 차시와 같은 틀)

`lesson.html?l=차시` — 차시마다 수업 지도안을 바탕으로 구성했습니다.

| 탭 | 내용 |
|---|---|
| PPT | 웹 슬라이드 8~9장 + 썸네일 + 발표자 메모. 활동 슬라이드에는 연결된 활동지 번호가 표시됨 |
| 활동지 | 학생 웹 활동지(`sheet.html`)를 화면 안에 띄움 |
| 수업 안내 | 도입·전개·정리 단계와 시간(40분), 핵심 질문, 준비물, 휴먼스킬, 지도할 때 유의점 |
| 선생님 자료 | 휴먼스킬 목표(지식·이해 / 과정·기능 / 가치·태도), 평가 기준(상·중·하), 수업 준비 메모, 자료 링크 |

- **수업 모드**: 슬라이드를 크게 띄움. ← → 키로 넘기고, 활동지가 연결된 장에서는 **활동지** 버튼이 주황색으로 빛남(W 키로 활동지 ↔ PPT). 메모, 전체 화면, 실시간 현황
- 주소에 `&s=장번호`를 붙이면 그 장부터 열림
- **수업 PPT(.pptx)**: `files/차시/ppt.pptx` — 웹 슬라이드와 같은 내용, 발표자 메모는 슬라이드 노트, 글꼴 맑은 고딕. PPT 탭과 선생님 자료 탭에서 내려받기
  - `data/lessons.json`을 고친 뒤 다시 만들기: `node tools/build_pptx.js` (한 차시만: `node tools/build_pptx.js 3`). pptxgenjs 필요
- 내용은 `data/lessons.json`에서 고칩니다. 슬라이드 `layout`: cover · map · talk · goal · cards · activity · matrix · match · split · sentence · next · finish. `sheet`: 연결할 활동지 파트 번호(0부터)

## 수업하기 (교실 링크 없이, 이 사이트 안에서)

`class.html` — 교실 링크 간단판. 학생 화면 공유는 없음.

- 선생님: 이름 + **초대 코드**(교실 링크 초대 코드, 요청은 classlink@biossam.kr)로 **수업 열기** → 6자리 참여 코드·QR → 차시·활동을 골라 **학생 화면에 띄우기**, **링크·파일 보내기**(8 MB 이하), **실시간 현황**, **수업 끝내기**
- 학생: `class.html`에서 코드 입력(또는 `class.html?room=코드`, QR) → 선생님이 띄운 활동지가 자동으로 열리고 바뀜(같은 차시 안에서 활동만 바뀌면 쓴 내용 그대로 그 칸으로 이동), 받은 자료 목록
- 차시 화면: 이 기기에서 연 수업이 있으면 **학생 화면에 이 차시 띄우기**, 수업 모드의 **학생에게 활동지 띄우기**, 실시간 현황이 바로 연결됨
- 서버: 교실 링크 서버의 `/api/mdk`(수업·띄우기·자료) + `/api/snja`(활동지 저장·현황). 수업을 끝내거나 선생님 창이 3시간 넘게 닫혀 있거나 연 지 12시간이 지나면 기록과 파일이 모두 지워짐

- **시연용 수업**: 코드 없이 열 수 있지만 1시간 뒤 닫히고, 파일은 못 보내고, 링크는 무.도.키즈 주소만 보낼 수 있어요.

## 웹 활동지 · 실시간 수업 (교실 링크 연동)

- 학생 활동지: `sheet.html?l=차시&room=참여코드` — 반·번호·모둠을 쓰면 몇 초마다 교실 링크 서버(`data/sheets.json`의 `live.url`)로 저장. 이름은 기기에만 남음. **다 했어요**로 제출, **활동지 그림으로 저장**(PNG)
- 모둠 칸(`"who": "모둠"`): 같은 모둠 학생끼리 같은 칸을 함께 씀 (칸마다 마지막에 쓴 내용이 남음)
- 실시간 현황의 **평가 초안**: 차시 평가 기준(`data/lessons.json`의 `eval`, `parts`=근거가 되는 활동지 파트)으로 학생별 상·중·하 제안과 근거, 피드백 한 마디, 학급 전체 요약. 칸을 채운 정도·까닭 표현·쓴 분량만 보는 자동 초안이라 선생님이 고칠 수 있고(이 기기에만 저장), **AI에 물어볼 프롬프트 복사**(이름 없이 반·번호와 답안)로 내용까지 본 초안을 받음. CSV에 평가 칸 포함
- 실시간 현황: `live.html?l=차시` — 교실 링크 교사 화면 → **무.도.키즈 활동지** 탭 → **실시간 현황**으로 열면 참여 코드와 교사 키가 주소 `#` 뒤로 넘어와 자동 연결(받자마자 주소에서 지움). 학생별 진행·제출·답 보기, 칸별로 모아 보기, 기기 잠금 풀기, 기록 지우기, CSV 받기
- 서버의 성장 MAP 활동지 API(`/api/snja`)를 그대로 씀. 성장 MAP 차시와 섞이지 않게 **51~60차시**(`lessonOffset` 50)로 저장
- 학생 화면 공유(학생 → 선생님)는 쓰지 않음
- 교실 링크 없이 열면 그 기기에만 저장됨
- 시험할 때: 주소에 `&server=http://내서버` 를 붙이면 다른 교실 링크 서버로 연결

활동지 칸은 `data/sheets.json`에서 고칩니다. 칸 종류: `text`(여러 줄), `line`(한 줄, `prefix`·`suffix`로 문장 완성), `chips`(여러 개 고르기, `max`), `pick`(하나 고르기). `optional: true`면 진행률에서 뺌. 칸 `id`를 바꾸면 이미 쓴 내용과 연결이 끊기니 수업 중에는 바꾸지 마세요.

## 고치는 법

- 내용은 모두 `index.html`에 그대로 적혀 있습니다. 차시 카드는 `<details class="lesson" id="l1">` … `id="l10"`.
- ‘준비 중’ 칸을 채울 때는 `#stories` 구역의 `card pending`을 일반 `card`로 바꾸고 내용을 넣으면 됩니다.
- 색과 글꼴은 `assets/css/style.css` 맨 위 `:root`에서 바꿉니다.

## 휴먼스킬 사전·사후 설문

- 학생: `survey.html?phase=pre|post&room=코드&skills=agency,critical` — 문항은 `data/survey.json`(휴먼스킬 12개 × 3문항(지식·이해 · 과정·기능 · 가치·태도) = 연구회 실제 설문 36문항, 5점 얼굴 단추, 열린 질문 1개).
- 선생님: 수업하기 → 휴먼스킬 설문에서 휴먼스킬을 고르고 사전/사후 설문 띄우기. 서버에는 61(사전)·62(사후)차시로 저장되고, 고른 휴먼스킬은 push의 `opt`로 학생 화면에 전달됩니다.
- 결과: `survey-results.html` — 휴먼스킬별 사전·사후 평균, 같은 반·번호끼리 비교한 변화, 문항별 평균, CSV. 수업 기록은 12시간 뒤 지워지므로 사전 결과 CSV를 받아 두었다가 사후 때 **지난 CSV 불러오기**로 합칩니다.

## 휴먼스킬 탭 · 체크리스트 탭

- 휴먼스킬 탭(`index.html#skills`)은 `tools/build_skills.py`가 `data/lessons.json`(차시별 알기·하기·가치), `data/sheets.json`(차시 글자·제목), `data/survey.json`(한 줄 풀이 `desc`, 설문 문항)으로 만듭니다. 지도안 휴먼스킬을 고치면 `python3 tools/build_skills.py`를 다시 실행하세요.
- 한 줄 풀이(`desc`)는 학생에게 설명하기 쉽게 쓴 것으로, 연구회 공식 정의가 정해지면 `data/survey.json`에서 바꿉니다.
- 체크리스트 탭: AI 도구 쓰기 전 체크리스트 + 수업하기 체크리스트(수업 전·중·후, 휴먼스킬). 체크 표시는 저장되지 않습니다.
- 휴먼스킬 세 갈래(중심잡기·성찰하기·융합하기)와 12가지 틀의 출처: 김현철(고려대학교 컴퓨터학과 교수), 「인간중심사고 AI : 휴먼스킬」, 네이버커넥트재단 테크런 (https://techrun.connect.or.kr/online/course/83/lecture/107). `data/survey.json`의 `axes`·`axis`에 담겨 있습니다.

## 수업 이야기 탭 · 따라 하기 체크리스트

- `data/stories.json`(연구회 신청서의 1차 수업에서 바꾼 점, 사전·사후 설문 결과, 학생 인터뷰, 따라 하기 체크리스트, 우리 학교에 맞게 바꾸려면) → `python3 tools/build_stories.py`가 수업 이야기 탭과 체크리스트 탭의 '따라 하기 체크리스트'를 만듭니다.
- 휴먼스킬 탭의 강의 설명(`data/survey.json`의 `coreDef`, `axes[].desc`, `skills[].lecture`)은 김현철 교수 테크런 강의 화면의 문구입니다.
